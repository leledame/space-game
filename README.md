# Space Game 🚀
*Игра, где игрок при помощи своего пальца контролирует положение космического корабля на экране, избегая пролетающий мусор.*
## Описание
Главная цель игры — продержаться как можно дольше и набрать наибольшее количество очков сбивая лазером пролетающий мимо мусор.
В начале игры у космического корабля 3 очка здоровья (жизни). При возникновении контакта между космическим кораблём и мусором,
у игрока снимается одно очко жизни и мусор пропадает. Когда количество очков жизни становится равным нулю — игра завершается.
## Технологии
Язык программирования Java с использованием фреймворка LibGDX.
